# Example patches

Patches produced by the models in recorded runs (`results/` has the matching rows). Each folder has `patch.diff` (the accepted patch), `attempts.md` (gate outcome per attempt, the model's own diagnosis, the differential counterexample where there was one) and `meta.json`. Accepted means: passed the gates that were on in that run. It does not mean the patch is correct beyond those checks. The folder `p4-spark-gate-off-accepted-but-diverges` shows a patch accepted without the differential gate that failed the differential check afterwards. Generated by `scripts/make_showcase.py`.
