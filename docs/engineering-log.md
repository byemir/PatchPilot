- Added patchpilot/differential.py: generated-input differential. Oracle = ORIGINAL code on the OLD library; candidate = PATCHED code on the NEW and on the OLD library. Inputs come from a seeded, stdlib-only mutator over the seed probes (inputs.json + hidden_inputs.json): per-JSON-path value envelopes for numbers, digit-run mutation and token crossover for strings, drop/dup/shuffle/grow/truncate for lists. Reproducible (seed) and zero model tokens.
- Design: two tiers. "core" probes keep numbers inside the envelope seen in the seeds and any divergence fails; "wide" probes leave it and are only reported, because out-of-contract inputs can legitimately differ (np.asarray([-1], dtype=uint8) raises OverflowError on NumPy 2 and wraps on 1.x, nothing a patch should preserve). Probes where the oracle itself raised are skipped. Fewer than 20 valid probes gives verdict WEAK instead of a silent pass.

- OS isolation layer for model code (macOS sandbox-exec; patchpilot/sandbox.py, meta_client.py, bench.py, agent.py, validate_case.py, negative_test.py, isolation_test.py). Behavior: bench and agent re-exec themselves with a minimal environment (kept names: PATH, HOME, LANG, LC_ALL, LC_CTYPE, TMPDIR, TERM, USER, LOGNAME, PP_CLEAN); the API key is read at call time from ~/.config/patchpilot/meta_key (directory 0700, file 0600, checked on every read) and never from or into the environment; before model code runs, the harness reads its own initial environment the way same-user code could (sysctl KERN_PROCARGS2) and refuses if a variable name contains KEY, TOKEN, SECRET, PASSW, CREDENTIAL, AUTH or CANARY, or a value looks key-shaped (32 or more characters of [A-Za-z0-9_-], or sk- followed by 16 or more); the profile denies read and write under the home directory and the repository (except read of .sandboxes and the interpreter prefix) and denies network; a four-probe self-test runs once per interpreter before model code and refuses on any result other than denied; --no-fs-deny disables the layer, marks records fs_deny=false, gives bench result files the suffix _NOFSDENY and counted=false; validate_case runs without the layer by default (fixtures are trusted) and with --fs-deny when asked. This local runner is not a hardened security boundary: model code runs on this machine with the user's privileges.
