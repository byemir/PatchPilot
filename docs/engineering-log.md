- Added patchpilot/differential.py: generated-input differential. Oracle = ORIGINAL code on the OLD library; candidate = PATCHED code on the NEW and on the OLD library. Inputs come from a seeded, stdlib-only mutator over the seed probes (inputs.json + hidden_inputs.json): per-JSON-path value envelopes for numbers, digit-run mutation and token crossover for strings, drop/dup/shuffle/grow/truncate for lists. Reproducible (seed) and zero model tokens.
- Design: two tiers. "core" probes keep numbers inside the envelope seen in the seeds and any divergence fails; "wide" probes leave it and are only reported, because out-of-contract inputs can legitimately differ (np.asarray([-1], dtype=uint8) raises OverflowError on NumPy 2 and wraps on 1.x, nothing a patch should preserve). Probes where the oracle itself raised are skipped. Fewer than 20 valid probes gives verdict WEAK instead of a silent pass.
